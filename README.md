# REGALIA INFRA — Website Wireframe

Frontend-only React + Vite wireframe. No backend, no API keys; forms send nothing.

## Run
```
npm install
npm run dev        # http://localhost:5173
npm run build && npm run preview   # http://localhost:4173
```

## Pages
/, /about, /services, /services/{retail-leasing, brand-expansion, residential, commercial},
/opportunities, /opportunities/:slug, /partner-with-us, /contact, /thank-you, /privacy, /terms, 404.

Sample opportunities live in `src/data/content.js` (OPP-004 is marked unavailable to show that state).
